About

{{ site_name }} shows how early or late spring came this year in European cities, each against its own {{ baseline }} average. The date comes from a published model of when lilac and honeysuckle first bloom, run on daily temperatures from the EU's Copernicus Climate Change Service. In Germany and Sweden it has been checked against observed lilac bloom. How it works

The idea

In the United States, the USA National Phenology Network maps the start of spring with the Extended Spring Indices and compares each year with the 1991–2020 average. {{ site_name }} brings the same idea to European cities: the first-bloom index of the same published model, unchanged, and the same average, run on European temperature data and checked against European observations.

The name

Kiuru is Finnish for the skylark. An old Finnish saying counts down to summer from the return of three birds: Kuu kiurusta kesään, puolikuuta peipposesta, västäräkistä vähäsen, a month from the skylark to summer, half a month from the chaffinch, a little from the white wagtail. In 2019 the Finnish Nature Association (Luontoliitto) pointed out that warming has moved the birds' arrival earlier, so the saying no longer holds as well.
