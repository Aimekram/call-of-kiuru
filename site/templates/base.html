What this number is

The start of spring shown here is a model result, not an observation. It is the first-bloom index of the Extended Spring Indices (SI-x), a published model that estimates from daily temperatures when early-spring plants such as lilac and honeysuckle first bloom. Each city is compared with the model's own {{ baseline }} average for that city.

Temperatures come from the ERA5 reanalysis, which arrives about five days late. Data updated {{ updated }}.
